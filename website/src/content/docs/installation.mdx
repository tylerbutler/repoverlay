Choose a method for your platform. Homebrew works on macOS and Linux;
PowerShell is for Windows. Cargo requires Rust 1.91 or later.

<Tabs>
	<TabItem label="Homebrew">
		**Install:**
		```bash
		brew install tylerbutler/tap/repoverlay
		```

		**Update:**
		```bash
		brew update && brew upgrade repoverlay
		```

		**Uninstall:**
		```bash
		brew uninstall repoverlay
		```
	</TabItem>
	<TabItem label="Shell script">
		**Install:**
		```bash
		curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tylerbutler/repoverlay/releases/latest/download/repoverlay-installer.sh | sh
		```

		The installer puts the binary in `$CARGO_HOME/bin`. If `CARGO_HOME` is not set, it uses `$HOME/.cargo/bin`.

		**Update:**
		Run the install command again to replace the binary.

		**Uninstall:**
		```bash
		rm "${CARGO_HOME:-$HOME/.cargo}/bin/repoverlay"
		```
	</TabItem>
	<TabItem label="PowerShell">
		**Install:**
		```powershell
		irm https://github.com/tylerbutler/repoverlay/releases/latest/download/repoverlay-installer.ps1 | iex
		```

		The installer puts the binary in `$env:CARGO_HOME\bin`. If `CARGO_HOME` is not set, it uses `$env:USERPROFILE\.cargo\bin`.

		**Update:**
		Run the install command again to replace the binary.

		**Uninstall:**
		```powershell
		$cargoHome = if ($env:CARGO_HOME) { $env:CARGO_HOME } else { Join-Path $env:USERPROFILE ".cargo" }
		Remove-Item (Join-Path $cargoHome "bin\repoverlay.exe")
		```
	</TabItem>
	<TabItem label="Cargo">
		Build from source with Cargo, or use `cargo-binstall` for a prebuilt binary.
		If you do not have `cargo-binstall`, install it first:

		```bash
		cargo install cargo-binstall
		```

		**Install:**
		```bash
		# Install a pre-built binary (faster)
		cargo binstall repoverlay

		# Build from source
		cargo install repoverlay
		```

		**Update:**
		```bash
		cargo binstall repoverlay --force
		# or
		cargo install repoverlay --force
		```

		**Uninstall:**
		```bash
		cargo uninstall repoverlay
		```
	</TabItem>
</Tabs>

## Manual

Download the prebuilt binary for your platform from [repoverlay releases](https://github.com/tylerbutler/repoverlay/releases).

**Update:** Download and replace the binary on your PATH.

**Uninstall:** Delete the binary from your PATH.

## Confirm installation

```bash
repoverlay --version
```

If the terminal cannot find the command, restart it. Make sure that the installation
directory is on your PATH. Cargo installs to `$CARGO_HOME/bin`, or
`$HOME/.cargo/bin` by default. On Windows the default is
`$env:USERPROFILE\.cargo\bin`.

When the terminal shows the version, [apply your first profile](/quick-start/#try-it).
