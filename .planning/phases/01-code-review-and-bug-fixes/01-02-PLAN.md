**FIX-02: Error display format (main.rs line 7)**

Change Debug format to Display format in the error handler:
```rust
// BEFORE:
eprintln!("Error: {e:?}");

// AFTER:
eprintln!("Error: {e:#}");
```

The `#` (alternate) flag on `anyhow::Error` prints the full error chain in human-readable format with `: ` separators. Without `#`, Display shows only the top-level error. With `#`, it shows the full chain.

**FIX-03: SIGPIPE handling (main.rs)**

Add SIGPIPE reset at the very start of main(), before any output:
```rust
fn main() {
    // Reset SIGPIPE to default so piped commands exit cleanly.
    // Rust's runtime masks SIGPIPE, causing "Broken pipe" errors
    // when output is piped to commands like `head`.
    #[cfg(unix)]
    unsafe {
        libc::signal(libc::SIGPIPE, libc::SIG_DFL);
    }

    env_logger::init();

    if let Err(e) = repoverlay::run() {
        eprintln!("Error: {e:#}");
        std::process::exit(1);
    }
}
```

Add `libc` as a dependency in Cargo.toml:
```toml
[dependencies]
libc = "0.2"
```

Note: `libc` is already a transitive dependency (via crossterm, nix, etc.) so this adds no new download. The `#[cfg(unix)]` guard ensures this only compiles on Unix platforms.
