Create the `docs/manual-tests/` directory and write 4 manual test documents.

**Document structure for each file:**

```markdown
# [Command] - Manual Test

## Prerequisites
- repoverlay installed and on PATH
- git installed

## Setup
[Create temp directory, init git repo, create test overlay with repoverlay.ccl]

## Test Cases

### TC-01: [Scenario Name]
**Steps:**
[Copy-pasteable commands]

**Expected Output:**
[What the terminal should show]

**Verify:**
[How to check the result is correct]

## Cleanup
rm -rf "$TEST_DIR"
```

**Each document must:**
- Start with `TEST_DIR=$(mktemp -d)` for clean isolation
- Create a local overlay with at least one file and a `repoverlay.ccl` config
- Use `cd "$TEST_DIR"` consistently
- Include verification steps (ls, cat, file existence checks)
- NOT require network access for core test cases

**apply.md (MANUAL-01)** — Test cases:
- TC-01: Apply local overlay (symlink mode, default) — verify symlink created, git exclude updated
- TC-02: Apply with --copy — verify file is a copy not symlink
- TC-03: Apply with --name override — verify overlay listed under custom name
- TC-04: Apply with --dry-run — verify no files created
- TC-05: Apply with --force to re-apply same overlay — verify files updated
- TC-06: Apply with --skip-conflicts when target has conflicting file — verify non-conflicting files applied
- TC-07: Apply with --merge on JSON files — verify JSON deep merge
- Optional (requires network): Apply from GitHub URL

**remove.md (MANUAL-02)** — Test cases:
- TC-01: Remove named overlay — verify files and state removed, git exclude cleaned
- TC-02: Remove with --all — verify all overlays removed
- TC-03: Remove with --dry-run — verify no changes made
- TC-04: Remove non-existent overlay — verify clear error message

**status.md (MANUAL-03)** — Test cases:
- TC-01: Status with no overlays — verify appropriate message
- TC-02: Status with applied overlay — verify overlay info displayed
- TC-03: Status with --json — verify valid JSON output
- TC-04: Status with --quiet — verify exit code only (0 with overlays, 1 without)
- TC-05: Status with --name filter — verify only named overlay shown

**restore.md (MANUAL-04)** — Test cases:
- TC-01: Apply overlay, delete the symlinked file, restore — verify file recreated
- TC-02: Restore with --dry-run — verify no changes made
- TC-03: Restore with --force when conflicting file exists — verify file overwritten
