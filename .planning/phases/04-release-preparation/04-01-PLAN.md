# Plan 04-01: README Review and Crates.io Metadata

## Objective

Review README.md for accuracy against the actual CLI surface and verify crates.io metadata is complete. This is the final release gate for v0.8.

## Context

**Actual CLI commands** (from `repoverlay --help`):
- apply, remove, status, restore, update, create, switch, cache, browse, sync, edit, source, completions

**README gaps identified during audit:**
1. `repoverlay add` is documented as top-level command but does NOT exist — the actual command is `edit --add`
2. `edit` command is not documented at all
3. `completions` command is not documented
4. `source` subcommands have no dedicated Usage section (only in Quick Reference)
5. Quick Reference table shows `add` and `sync` but `edit` is missing
6. Various flags missing from docs: `--interactive`, `--skip-conflicts`, `--merge`, `--from`, `status --json/--quiet`

**Cargo.toml metadata** (currently):
- name: repoverlay
- description: "Overlay config files into git repositories without committing them"
- license: MIT
- keywords: ["git", "overlay", "config", "symlink"]
- categories: ["command-line-utilities", "development-tools"]
- repository/homepage: set

## Tasks

### Task 1: Update README.md

**What:**
1. Fix Quick Reference table:
   - Remove `Add files to overlay | repoverlay add <name> <files>` (command doesn't exist)
   - Add `Edit overlay | repoverlay edit <name> --add <files>`
   - Add `Shell completions | repoverlay completions <shell>`
2. Fix "Add files to an existing overlay" section → rename to "Edit an overlay" and update commands to use `edit --add` / `edit --remove` / `edit --interactive`
3. Add "Manage overlay sources" section under Usage:
   ```
   repoverlay source add owner/repo
   repoverlay source list
   repoverlay source remove my-source
   ```
4. Add "Shell completions" section:
   ```
   repoverlay completions bash > ~/.bash_completion.d/repoverlay
   repoverlay completions zsh > ~/.zsh/completions/_repoverlay
   repoverlay completions fish > ~/.config/fish/completions/repoverlay.fish
   ```

**Acceptance:**
- Every command in `repoverlay --help` has corresponding documentation
- No documentation references non-existent commands
- Quick Reference table matches actual CLI surface

### Task 2: Verify Cargo.toml metadata

**What:**
1. Verify all required crates.io fields are present and correct
2. Check `readme = "README.md"` is set (or defaults correctly)
3. Verify `exclude` patterns are sensible (no test fixtures, docs, or planning dirs published)
4. Verify keywords are relevant (max 5 for crates.io)
5. Verify categories exist on crates.io

**Acceptance:**
- `cargo package --list` shows only expected files
- All crates.io metadata fields are set
- `cargo publish --dry-run` succeeds (or note any issues)
