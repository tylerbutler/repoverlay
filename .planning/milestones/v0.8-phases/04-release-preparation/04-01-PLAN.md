# Plan 04-01: README Review and Crates.io Metadata

## Objective

Simplify README.md by replacing detailed per-command Usage sections with a link to the existing CLI reference (`docs/cli-reference.md`), fix the inaccurate `add` command documentation, and verify crates.io metadata.

## Context

**Existing CLI reference:** `docs/cli-reference.md` — generated by clap-markdown, covers all commands with full flag documentation.

**README inaccuracies:**
1. `repoverlay add` documented as top-level command but does NOT exist — actual command is `edit --add`
2. `edit` command missing from Quick Reference table
3. Detailed Usage sections duplicate what's already in cli-reference.md

**User decision:** Link to CLI reference docs instead of duplicating command docs in README.

## Tasks

### Task 1: Simplify README.md

**What:**
1. Fix Quick Reference table:
   - Remove `Add files to overlay | repoverlay add <name> <files>` (command doesn't exist)
   - Add `Edit overlay | repoverlay edit <name> --add <files>`
   - Add `Manage sources | repoverlay source add/list/remove`
   - Add `Shell completions | repoverlay completions <shell>`
2. Replace the detailed per-command Usage sections (from "## Usage" through "### Manage cache") with:
   - A brief "## Usage" section showing 2-3 key examples (apply local, apply GitHub, remove)
   - A link to `docs/cli-reference.md` for full command reference
3. Keep: Concepts, Installation, Overlay Configuration, License sections unchanged

**Acceptance:**
- Quick Reference table matches actual `repoverlay --help` command list
- No references to non-existent `add` command
- Link to cli-reference.md present
- README is shorter and more focused

### Task 2: Verify Cargo.toml metadata

**What:**
1. Verify all required crates.io fields are present and correct
2. Check `readme = "README.md"` is set (or defaults correctly)
3. Verify `exclude` patterns keep test fixtures, docs, and planning dirs out of published crate
4. Verify keywords (max 5) and categories are valid for crates.io
5. Run `cargo package --list` to check what gets published

**Acceptance:**
- All crates.io metadata fields set
- `cargo package --list` shows only expected files
- Exclude patterns prevent publishing `.planning/`, `docs/`, `mutants.out/`
